description: 공모주 캘린더의 인기종목·FAQ를 수정할 때 지켜야 할 화면 기준
---

공모주 캘린더, 인기종목, FAQ는 저장된 원본 캘린더 화면의 메뉴와 섹션 구조를 유지하고, 별도 화면으로 다시 만들지 않는다.

**Why:** 별도로 만든 React 메뉴와 화면은 기능이 같아도 원본 페이지와 시각적·구조적으로 달라 사용자 요구에 맞지 않았다.

**How to apply:** 원본 HTML 안의 세 섹션을 그대로 사용하고, 관리자 연동 데이터나 문구 변경은 원본 DOM 내부에 주입한다.
