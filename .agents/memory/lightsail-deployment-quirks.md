---
name: Lightsail 배포 주의점
description: 단일 Ubuntu 서버 배포에서 확인된 npm 및 PM2 운영 제약
---

운영 환경에서도 스키마 적용과 프런트엔드 빌드가 끝나기 전까지 개발 의존성을 제외하지 않는다. 자동 배포에서는 앱 스키마에 선언되지 않은 세션 테이블을 전체 스키마 동기화로 삭제하지 말고, 필요한 변경만 멱등적으로 적용한다. 운영 서버 시작 시 초기 데이터 생성과 과거 거래 보정을 자동 실행하지 않는다. PM2 자동 시작을 등록할 때는 기존 사용자 PM2 데몬을 종료한 뒤 systemd가 저장된 프로세스를 직접 복원하게 한다.

**Why:** `NODE_ENV=production` 상태의 기본 npm 설치는 빌드 도구를 제외한다. 전체 Drizzle push는 별도 라이브러리가 만든 세션 테이블을 삭제 대상으로 판단할 수 있다. 시작 시 보정 함수는 기존 거래 행을 수정하거나 새 행을 추가할 수 있어 무변경 배포 원칙에 어긋난다. 이미 실행 중인 PM2 데몬은 systemd의 PID 추적과 충돌해 서비스 시작이 실패할 수 있다.

**How to apply:** Lightsail 신규 배포와 서버 재구성에서 의존성 설치 옵션, 비파괴 DB 준비 명령, 운영 시작 보정 차단, PM2 systemd 전환 순서를 함께 점검한다.
