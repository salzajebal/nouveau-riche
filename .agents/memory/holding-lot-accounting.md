---
name: 입고 건별 보유단가
description: 동일 종목의 여러 입고 건을 표시하고 출고 수량을 차감하는 확정된 회계 원칙
---

동일 회원이 같은 종목을 서로 다른 단가로 입고하면 평균으로 합치지 않고 입고 건마다 별도 보유 행으로 표시한다. 일반 차감은 오래된 입고 건의 잔량부터 처리하되, 회원이 출고할 입고 건을 직접 선택한 경우에는 해당 입고 건만 예약하고 차감한다. 예약된 입고 건은 확정매도, 회원 간 이전, 관리자 수기 출고, 다른 출고 신청이 소비할 수 없다.

**Why:** 사용자가 같은 종목·같은 카테고리라도 매입단가가 다른 입고 건을 각각 선택해 출고해야 한다고 명시했다. 카테고리나 종목 합계만 예약하면 다른 차감 작업이나 승인 순서에 따라 선택한 단가의 물량이 사라질 수 있다.

**How to apply:** 회원 보유 현황, 평가손익, 출고, 매도, 회원 간 이전, 관리자 거래 기능을 변경할 때 입고 건별 단가와 잔량을 보존한다. 특정 입고 건의 활성 출고 예약은 회원 단위 동시성 잠금 안에서 모든 주식 차감 경로보다 우선 보호한다.
