---
name: 입고 건별 보유단가
description: 동일 종목의 여러 입고 건을 표시하고 출고 수량을 차감하는 확정된 회계 원칙
---

동일 회원이 같은 종목을 서로 다른 단가로 입고하면 평균으로 합치지 않고 입고 건마다 별도 보유 행으로 표시한다. 출고 시에는 오래된 입고 건의 잔량부터 차감하는 선입선출 방식을 적용한다.

**Why:** 사용자가 500원 입고분과 700원 입고분이 마이페이지에서 각각 별도 행으로 보여야 한다고 명시적으로 확인했다.

**How to apply:** 회원 보유 현황, 평가손익 또는 관련 기능을 변경할 때 입고 건별 단가와 잔량을 보존한다. 종목별 총수량이 필요한 선택·검증 UI에서만 잔량을 합산한다.
