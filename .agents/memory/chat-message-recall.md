---
name: 상담 메시지 회수
description: 1:1 상담의 읽음 판정, 메시지 회수 및 자주 쓰는 문구에 관한 확정 원칙
---

관리자가 보낸 상담 메시지는 회원 화면에 표시되기 전까지만 회수할 수 있다. 읽음 처리는 상담방 전체가 아니라 회원 화면에 실제 표시된 관리자 메시지 ID별로 기록한다. 기존 메시지는 기능 도입 시 이미 읽은 것으로 취급한다.

**Why:** 방 전체 읽음 처리는 기록 조회 실패 시 회원이 보지 못한 메시지까지 회수 불가능하게 만들며, 실시간 이벤트와 기록 조회가 겹치면 삭제된 메시지가 다시 나타날 수 있다.

**How to apply:** 채팅 동기화를 변경할 때 방 소유권 검증, 입장 확인 후 전송, 기록 조회 중 실시간 이벤트 순서 보존, 조건부 회수를 함께 유지한다. 자주 쓰는 문구는 모든 관리자에게 공통인 DB 데이터로 관리한다.
